# Contributing

AI-assisted contributions are accepted with disclosure.

- Add an `Assisted-by` trailer for each model used.
- Example: `Assisted-by: Claude Code:claude-opus-5-5`.
- Never use `Co-Authored-By` for a model.
- The contributor has read and understood every line.
- The PR description gives evidence that `just check` passed.
- Paste the `just check` summary in the PR description.

Use Conventional Commits.

A single maintainer reads every diff before it lands on main.
